**Выполнил:** Токарев Егор группа 444

**Задача:** Создать API для компании "Просто лететь" сервиса бронирования и заказа авиабилетов.

## Стек:
- **PHP** 8.3 / **Laravel** 13.33
- **PostgreSQL** 16
- **Docker** — контейнеризация частей проекта
- **Adminer** — для просмотра БД через браузер

## Возможности
- **Регистрация и вход** — signup / login, выдача `api_token`
- **Каталог товаров** — просмотр доступен всем, создание/редактирование/удаление — только администратору
- **Корзина** — добавление товара, просмотр содержимого, удаление позиции
- **Заказы** — оформление заказа из корзины (цена считается автоматически, корзина очищается), список своих заказов
- **Профиль** — просмотр и редактирование своих данных (ФИО, email, пароль, аватар)
- **Роли** — `client` и `admin`, доступ к админ-эндпоинтам проверяется отдельным middleware

### Гостевые эндпоинты
| Метод | Путь        | Описание       |
|-------|-------------|----------------|
| POST  | `/signup`   | Регистрация    |
| POST  | `/login`    | Вход           |
| GET   | `/products` | Список товаров |

### Требуют авторизации
| Метод  | Путь              | Описание                      |
|--------|-------------------|-------------------------------|
| GET    | `/logout`         | Выход                         |
| GET    | `/profile`        | Профиль текущего пользователя |
| PATCH  | `/profile`        | Обновление профиля            |
| GET    | `/cart`           | Содержимое корзины            |
| POST   | `/cart/{product}` | Добавить товар в корзину      |
| DELETE | `/cart/{cart}`    | Удалить позицию из корзины    |
| GET    | `/order`          | Список своих заказов          |
| POST   | `/order`          | Оформить заказ из корзины     |

### Только для администратора
| Метод  | Путь                 | Описание       |
|--------|----------------------|----------------|
| POST   | `/product`           | Создать товар  |
| PATCH  | `/product/{product}` | Обновить товар |
| DELETE | `/product/{product}` | Удалить товар  |

> Для тестирования всех эндпоинтов сделана Postman-коллекция.

cd project && composer install

# Запуск и настройка докера:

>Запустите свой докер

Перейдите в папку деплой

```
cd ../deploy
```

2 варианта: через sh скрипт или просто ввести команды самим

1 вариант:
chmod +x script.sh
./script.sh

2 вариант:

```
docker compose exec php composer update

docker compose exec php composer install

docker compose exec php php artisan key:generate

docker compose exec php php artisan migrate:fresh --seed
```



Если всё отработало верно то по http://localhost:8000 вы увидите стартовую страницу laravel
