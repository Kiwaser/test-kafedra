**Выполнил:** Токарев Егор группа 444

**Задача:** Создать API для компании "Просто лететь" сервиса бронирования и заказа авиабилетов.

## Стек:
- **PHP** 8.3 / **Laravel** 13.33
- **PostgreSQL** 16
- **Docker** — контейнеризация частей проекта
- **Adminer** — для просмотра БД через браузер

## Возможности
- **Регистрация и вход** — signup / login, выдача `api_token`
- **Каталог товаров** — просмотр доступен всем, создание/редактирование/удаление — только администратору
- **Корзина** — добавление товара, просмотр содержимого, удаление позиции
- **Заказы** — оформление заказа из корзины (цена считается автоматически, корзина очищается), список своих заказов
- **Профиль** — просмотр и редактирование своих данных (ФИО, email, пароль, аватар)
- **Роли** — `client` и `admin`, доступ к админ-эндпоинтам проверяется отдельным middleware

### Гостевые эндпоинты
| Метод | Путь        | Описание       |
|-------|-------------|----------------|
| POST  | `/signup`   | Регистрация    |
| POST  | `/login`    | Вход           |
| GET   | `/products` | Список товаров |

### Требуют авторизации
| Метод  | Путь              | Описание                      |
|--------|-------------------|-------------------------------|
| GET    | `/logout`         | Выход                         |
| GET    | `/profile`        | Профиль текущего пользователя |
| PATCH  | `/profile`        | Обновление профиля            |
| GET    | `/cart`           | Содержимое корзины            |
| POST   | `/cart/{product}` | Добавить товар в корзину      |
| DELETE | `/cart/{cart}`    | Удалить позицию из корзины    |
| GET    | `/order`          | Список своих заказов          |
| POST   | `/order`          | Оформить заказ из корзины     |

### Только для администратора
| Метод  | Путь                 | Описание       |
|--------|----------------------|----------------|
| POST   | `/product`           | Создать товар  |
| PATCH  | `/product/{product}` | Обновить товар |
| DELETE | `/product/{product}` | Удалить товар  |

> Для тестирования всех эндпоинтов сделана Postman-коллекция.

# Информация про то как его запустить:

```
cd project && cp .env.example .env
```

> В файл `.env.example` уже вписаны нужные данные бд для корректной работы докера, Для продакшена такие данные обычно убирают, но здесь они оставлены намеренно, поскольку проект тестовый

### Настройка докера:

>Запустите свой докер

Перейдите в папку деплой

```
cd ../deploy
```
> Поднимите контейнеры следующей командой

```
docker compose up -d
```

### После того как докер контейнеры собрались и запустились 2 варианта: через sh скрипт или самим вводить

1 вариант:

```
chmod +x script.sh
./script.sh
```


2 вариант:

```
docker compose exec php composer update

docker compose exec php composer install

docker compose exec php php artisan key:generate

docker compose exec php php artisan migrate:fresh --seed
```



## Если всё отработало без ошибок, то по http://localhost:8000 вы увидите стартовую страницу laravel

### Для просмотра бд используйте adminer

http://localhost:8000/adminer.php

### Информация для подключения в adminer
- **Движок**: PostgreSQL
- **Сервер**: pgsql
- **Имя пользователя**: postgres
- **Пароль**: 12345
- **База данных** laravel

### Пометка про тестирование бд

Перед тестом оформления заказа из корзины идёт тест на удаление, тоесть если вы запустили все запросы сразу то на оформление выдаст 422 ошибку. Я решил ошибку добавив перед ним ещё 1 добавление в корзину.

### Также для удобства тестирования добавлены переменные:
- **host**:Хост http://localhost:8000/api ,
- **bearer_token**: Токен пользователя, который будет сохраняться при регистрации js скриптом,
- **admin_token**: Токен админа для тестов функций администратора**,
- **user_token**: Токен пользователя для тестов клиентской части
- **user-token-login-logout**: Токен пользователя, который используется только для 2 тестов login и logout
